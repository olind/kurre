# kurre
Simple static HTML user interface to display recordings from BirdNET-PI. Not database. Just regenerated HTML files when rsyncing MP3s and detections.

The idea is to use an old Raspberry Pi with just a mic to record and classify birds. Then schedule a RSYNC job to another computer that builds the static HTML UI. 

Its not aiming to be a replacement for the beautiful BirdNET-PI UI.
